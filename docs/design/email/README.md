# Email design references

- `order-events/`: order confirmation, delivery, cancellation, return, and exchange designs (formerly `Email_templates/`).
- `post-order-workflows/`: approval, rejection, pickup, and refund designs (formerly `Templates_set_2/`).

These HTML files are design references. Runtime mail templates live in [`backend/src/main/resources/templates/mail/`](../../../backend/src/main/resources/templates/mail/).
