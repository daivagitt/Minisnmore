# Frontend

React 19, TanStack Start/Router, Vite, and Tailwind CSS. All commands below run from this directory.

```bash
npm ci
npm run dev
npm test
npm run check
npm run build
npm run preview
```

`src/` contains routes, components, API clients, hooks, state, integrations, bundled assets, and colocated tests. `public/` contains static files. `@/` resolves to `src/`; `src/routeTree.gen.ts` is generated by the router plugin. Shared test setup is `src/test/setup.ts`.

Build output is `dist/` and coverage output is `coverage/`. The repository's deployment scripts run these commands with this directory as their working directory.

Run `npm run check` for lint, strict TypeScript, import/export resolution, and coverage. Run `npm run check:imports` to verify imports using this package's TypeScript configuration. See [frontend architecture](../docs/frontend-architecture.md) for module responsibilities.
